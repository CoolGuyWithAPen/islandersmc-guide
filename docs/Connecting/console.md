# Consoles

To join Islanders MC on console, you will need to download the [NetherLink](https://netherlink.net/) app. Once the app is installed, open it and add a bedrock profile with your name. Then add the Islanders MC server like this:

```
Server name: Islanders MC
Server adress: islandersmc.net
Server port: 19132
```

Now select your profile, select the Islanders MC server, and press broadcast.

:::important
Make sure your console and phone are connected to the same network!
:::

Go to your worlds section and you should now see a LAN world, join that world and now you should be in the Islanders MC server!
