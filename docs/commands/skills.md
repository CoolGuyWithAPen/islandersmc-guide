# Skills

Skills can make a big difference in this server if you learn to master them!

An easy way to check your skills is by using the ```/skills``` command, and to view how those skills affected your stats, use ```/stats```.

:::tip
Use ```/[skillname]``` to quickly open up the skills menu to your desired skill!
:::

Here is a big list of all the possible skills you can train!
- Archery
- Fighting
- Defense
- Farming
- Foraging
- Mining
- Fishing
- Excavation
- Agility
- Alchemy
- Enchanting

In the ```/menu```, you might see that some commands require a specific level of a skill before you are able to use it, a good example would be ```/home```, requiring agility level 3.
