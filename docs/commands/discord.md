# Discord

This server is equiped with Discord SRV, allowing you to see in game chats on the Discord server and allowing members to use proximity chat throgh Discord!

---

List of commands:

1. ```/discord```
    - Gives you an invite link to join the Discord server, where you can find announcements, updates and chat with other members of the server!
2. ```/discord link```
    - Will output a code you send directly to the Islanders MC discord bot to link your Minecraft account to your Discord account. This allows you to join the voice chat in the Discord server that automatically moves you into a voice channel that is exclusively players near you, making cross platform proximity chat a thing!
