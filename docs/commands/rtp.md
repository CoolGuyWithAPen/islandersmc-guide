# Random teleport

The ```/rtp``` command is very simple, it's an abreviasion for "Random teleport". When you execute the command, a 5 second countdown will start, and at the end of the countdown, you will be teleported somewhere random on the servers map.

:::tip
You can only use this command once every minute
:::

For MVP players, you guys get teleported in a different region than regular players. This region has extra structures and is a lot further from spawn than the default spawn region.
